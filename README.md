# Summit Roofing - High-Converting Contractor Prototype

A mobile-first, high-converting prototype website built for **Summit Roofing** in Denver, Colorado. Designed to demonstrate a complete lead-capture workflow for residential & commercial roofing contractors with $0 operating costs.

---

## 🏗️ Architecture & Features

- **Mobile-First UX**: Responsive layout, thumb-friendly touch targets (≥48px), and sticky mobile bottom action bar with tap-to-call (`(303) 555-0147`) and instant estimate jump.
- **Contractor Trust Palette**: Dark Navy (`#0F2A44`) authority, Safety Amber (`#F59E0B`) conversion accents, clean white backgrounds, and Front Range weather messaging.
- **6 Specialized Services**: Roof Replacement, Roof Repair, Roof Inspection, Seamless Gutters, Storm Damage Repair, Commercial Roofing.
- **Interactive Lightbox Gallery**: 8 high-resolution curated project photos with local Colorado captions, full modal zoom, and keyboard navigation (`Esc`, `←`, `→`).
- **Social Proof & Reviews**: 3 authentic Denver-area customer testimonials and 4 core value proposition pillars.
- **Estimate Form Engine**:
  - Auto-masking phone input `(XXX) XXX-XXXX`.
  - Client-side validation with inline error messaging.
  - Multi-tier anti-spam defense: Hidden honeypot field (`company_website_url`) + submission speed barrier.
  - Dual cloud & local storage: Saves to Supabase `leads` table, dispatches email via Formspree, and synchronizes to local browser storage so the demo **never** breaks during review.
  - Automatic redirect to `thank-you.html`.
- **Prototype Leads Console (`/leads.html`)**:
  - Filter by status (`New`, `Contacted`, `Inspection Scheduled`, `Quoted`, `Closed`).
  - Search by Name, Phone, Email, or Address.
  - Direct click-to-call and click-to-email actions.
  - One-click CSV export and demo data reset.

## 🔌 Connecting Live Cloud Integrations (Optional)

All settings are centralized in `js/config.js`.

### 1. Formspree Email Notifications
1. Create a free account at [formspree.io](https://formspree.io).
2. Create a new form and copy the Form ID (e.g., `xpzgqwer`).
3. In `js/config.js`, set:
   ```javascript
   integrations: {
     formspreeId: "your-formspree-id"
   }
   ```

### 2. Supabase Cloud Database
1. Create a free project at [supabase.com](https://supabase.com).
2. Go to **SQL Editor** and run:
   ```sql
   create table leads (
     id bigint generated by default as identity primary key,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null,
     name text not null,
     phone text not null,
     email text not null,
     address text not null,
     roof_type text,
     service text,
     message text,
     status text default 'New'
   );

   alter table leads enable row level security;
   create policy "Allow public inserts" on leads for insert with check (true);
   create policy "Allow public reads" on leads for select using (true);
   ```
3. Copy your **Project URL** and **anon public key** from Project Settings -> API.
4. In `js/config.js`, paste:
   ```javascript
   supabaseUrl: "https://your-project.supabase.co",
   supabaseAnonKey: "eyJhbGciOi...",
   supabaseTable: "leads"
   ```

## 🧪 What to Test (QA Checklist)

1. **Form Validation**: Try submitting empty fields. Notice inline red validation messages and focus jump.
2. **Phone Formatting**: Type `3035550147` into the phone field and see it auto-format to `(303) 555-0147`.
3. **Form Submission**: Fill out the form and submit. Notice smooth loading state and transition to `thank-you.html`.
4. **Lead Appearance**: Visit `/leads.html` (or click "View Leads Table"). The lead you just submitted appears at the very top with a green `New` badge.
5. **Mobile Quick Bar**: Open on a mobile device or inspect at `390px` width. Notice the fixed bottom bar with "Call Now" and "Free Estimate".
6. **Gallery Lightbox**: Click any project photo to open the high-res lightbox. Use arrow keys (`←`, `→`) or click the chevron buttons to navigate.

## 🎨 Re-Skinning for Future Clients in 2 Minutes

To adapt this template for another contractor:
1. Open `js/config.js`.
2. Update the `company` object: `name`, `city`, `phone`, `email`, `serviceAreas`, and `trustLine`.
3. Everything on the landing page, thank-you page, gallery, and leads table will automatically update!
